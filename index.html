SEM-Based Well-being Assessment Tool

1. Set your baseline. In the table, enter how things currently stand: for each hazard, how prevalent it is (0–100%); for each preventive measure, how well it is implemented (0–100%).
2. Test one item at a time — use Control. The Control % column tests a single row in isolation: for a hazard it asks "what if we reduced this hazard by X%?"; for a preventive measure it asks "what if we implemented this measure X% closer to full?". The result appears immediately in that row's Item-level impact column. Nothing else on the page changes.
3. Test a full plan — use Revised. Set the Revised % column to describe a target scenario (or click "Copy baseline → revised" and adjust from there). The Item-level revised scenario panel on the right compares this whole plan against baseline.
4. Test an across-the-board change — use Global controls. In the bottom-right panel, set "reduce all hazards" / "increase all prevention" to see the effect of one uniform change applied to every item at once. This is separate from the table and never overwrites your Baseline or Revised values.

How to use this tool

1. Enter baseline values

Use the Baseline % column to describe the current workplace condition. For hazards, a higher value means the hazard is more prevalent. For preventive measures, a higher value means the measure is better implemented.

2. Define a revised scenario

Use the Revised % column to describe a target or improved workplace condition — for example, after a planned intervention. You can click "Copy baseline → revised" to start from your current values, then edit only the items you plan to change.

3. Test one item at a time (Control)

The Control % column lets you isolate a single hazard or preventive measure and see its effect on its own, without changing anything else. For a hazard row, the control percentage reduces that hazard. For a preventive measure row, it increases that measure toward full implementation (100%). The result shows immediately in the Item-level impact column of that row, colour-coded green (improves well-being) or red (worsens well-being).

4. Use global scenario controls

The global controls (bottom-right panel) apply one uniform change to all hazards or all preventive measures at once — useful for a quick "what if we improved everything by roughly the same amount" check. This only updates the Global scenario chart and figures; it never changes your table values.

5. Read the results

The well-being index is a structural-equation-model score, not a percentage or a bounded scale — focus on its direction (up or down) and the percentage change shown, rather than treating the number itself as "out of 100". Because percentage change is relative to baseline, it can look large if the baseline value is close to zero.

6. Export your results

Click "Export CSV" at any time to download the full table — baseline, revised, control, and item-level impact for every hazard and preventive measure — as a spreadsheet-ready file.

Recommended workflow

Set baseline → copy baseline to revised → edit the revised values for the items you plan to change → review the item-level chart and interpretation → use global controls separately for a quick uniform-change check → export when finished.
